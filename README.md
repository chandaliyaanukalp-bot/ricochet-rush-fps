# Ricochet Rush — Low-Poly FPS

A lightweight browser FPS prototype with WebGL 3D geometry, visible first-person weapon, stylized low-poly bot soldiers, arena cover, shooting, reloads, health, kill feed and a timed match.

## Run locally
Keep `index.html`, `style.css`, and `game.js` together. Open `index.html` in a modern desktop browser with internet access (Three.js loads from jsDelivr). Click Deploy, then click the game view to lock the mouse.

## Controls
- WASD / arrows: move
- Mouse: aim
- Left click: shoot
- Space: jump
- Shift: sprint
- R: reload
- Esc: release mouse / pause

## GitHub Pages
Upload all four files to the root of a repository. Go to Settings → Pages → Deploy from a branch, choose `main` and `/(root)`, then save.

This is a single-player prototype with bots, not online multiplayer. Requires WebGL and internet access for the Three.js CDN.
